* Context
Branch =comp-for-js-pb= started as a PRNG refactor mid-flight that did not
build/test green. This list took the branch to a steady state: the in-flight
PRNG work compiles and passes, every public feature is comprehensively tested,
security boundaries are evaluated and documented, and each feature has a
runnable org-babel example. As of this pass =bb bp= (format → lint → clj-test →
cljs-node-test) and =bb examples= are green.

Two decisions that shaped the work:
- *Canonical PRNG abstraction* — kept the cljc protocol
  =auto-opti.prng.stateful/PRNG= as canonical; the fast clj/cljs impls now
  implement it directly (map-of-fns kept only as =make-generators= for
  benchmarks / the map-based quality suite). See task 5.
- *Scope of =iterative.descent== — quarantined as experimental (task 10).

* Security evaluation
Note: no =eval= / =read-string= / =load-string= / =slurp= / =spit= / shell-exec
sinks exist anywhere in =src/=. The surface is small and concentrated in PRNG
semantics.

** DONE 11. Document PRNG security boundaries (not cryptographic)

secure (never use for keys/tokens/salts/nonces; use a CSPRNG) and flags the
fixed-default-seed footgun (every default =prng= produces the same stream).
Follow-up: mirror this onto the prng wiki page (=docs/wiki/=, a separate git
repo not touched here).

** DONE 12. Resolve thread-safety contract mismatch and seed validation

(=seed-schema=) and throws a clear =ex-info= on malformed input instead of a
later obscure NPE.
