#+title: auto-opti.crit-comp — runnable example

A criteria comparator decides whether solution 1 is =:better=, =:worst= or
=:equal= to solution 2 given their criteria maps. =crit-comp-fn= looks a
strategy up in =default-registry= by =:crit-comp-name= and returns a ready
comparator function =(fn [crit1 crit2] ...)=.

Source of truth: [[file:crit_comp.clj][crit_comp.clj]]. Run all examples with =bb examples=.

#+begin_src clojure
(require '[auto-opti :as-alias opti])
(require '[auto-opti.crit-comp :as crit-comp])

(def sol-a {:cost 12 :delay 2 :quality 100})
(def sol-b {:cost 13 :delay 2 :quality 100})

;; Hierarchical: rank by :cost first, then :delay (smaller is better).
(def hierarchical
  (crit-comp/crit-comp-fn
   #::opti{:crit-comp-name :hierarchise
           :order [#::opti{:crit-comp-name :smaller :crit-name :cost}
                   #::opti{:crit-comp-name :smaller :crit-name :delay}]}))
(hierarchical sol-a sol-b)             ;; => :better

;; Weighted-sum: combine criteria with weights, smaller sum is better.
(def weighted
  (crit-comp/crit-comp-fn
   #::opti{:crit-comp-name :weighted-sum
           :weights {:cost 10 :delay 100}}))
(weighted {:cost 12 :delay 2} {:cost 13 :delay 4})   ;; => :better

;; Single-criterion helper on bare values.
((crit-comp/crit-comp-fn #::opti{:crit-comp-name :smaller}) 12 20)   ;; => :better
#+end_src

#+RESULTS:
: hierarchise a vs b : :better
: weighted a vs b    : :better
: smaller 12 vs 20   : :better
