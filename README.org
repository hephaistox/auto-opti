`auto-opti` provides features for optimization. The library is agnostic from any rendering or solver technoglogy.

* Definitions
Important definitions concerning simulation and optimization:
** System
The system is the part of the real life that the optimization is dealing with.
** Model
A model is a simplification of the system that is learning something useful from it.
** Discrete event simulation
A simulation formalizes the system through its states and discrete events. A simulation evolves with time. It is often a software as it is easy to do in a computer program, but it is not limited to it.
* Motivations
Many libraries exist already for all features mentionned here, but:
- Specific features are missing like transformation, evaluation criteria, evaluation, ...
- Optimization should be agnostic of any execution environment (cli, backend, frontend, android, 32 vs 64 bits...)
- The assembly of all of that features is the responsability of the user, so it should not be done in advance. That said, assembly should be a no brainer and documented.
- That assembly should be the starting point for vizualization components.
